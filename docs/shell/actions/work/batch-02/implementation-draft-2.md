**1.** ACTIONS shrank from a thousand habits to twelve offers, and the narrowing
is itself the argument that these are not slop. An offer is only as real as the
mechanism that lets it speak and the hand that lets it answer, and a sentence
with neither is a ghost no matter how well it reads. The three kills of the first
hunt are three different ghosts: A07's dock already hides itself through the
engine's own intellihide, so that behaviour was owned before the sentence was
written; A11's parked machine has no host virtualization anywhere in the tree, so
its actuator does not exist; A05's caught corner has no global cursor stream, so
its moment cannot be sensed. The twelve that remain are the rows this test
spared, finished blocks the second hunt then read field by field and repaired
four of without striking any. Each survivor is deliberately slight — a
condition, one sentence, one verb in a nested pill, a gear box that grows where
the sentence spoke. Twelve is where usefulness ran out, not a round number the
funnel aimed at.

**2.** The engine is where a block's honesty is decided, and its rule is that
nothing senses without already arriving. Detectors are pure functions over
streams the collectors carry — the audio watcher, the Hyprland event socket, the
zsh bridge's exit code, the downloads poll — no detector owns a timer, adding
no new sensing. Two ratified laws bind every Fires line: the budget is a
priority queue ranked by expiry rather than by kind, never two in an hour, no
carryover, expiring moments first; and one mouth per cluster with
back-of-the-queue on refusal, so A12 and A01 do not talk over the same call.
Persistence is one layer with two homes: evidence — counters, hashes, medians,
histograms — under the launcher's stores, and a signed rule, one readable
line in the config rules directory; acceptance writes a rule, refusal only a
counter. A block's ability to speak follows from that layer: A09 speaks — shell
127, desktop table and launch seam all ship — A12 speaks, both halves live
booleans over a shipped `wpctl`. Nine wait one read or counter deeper — the
source-mute read from the dump already parsed, the pair-counters, the
reachable-test, the association memory, a console-class name, an eval-rail write,
one logind listener shared by A10 and A14 — and A13 waits on an actuator that is
not ours to build, the batch's only [new].

**3.** The surface is carried over, and the carrying is the point: the twelve
blocks speak through the pill, the nested verbs, the gear box and the grow morph
that the sunset prototype has exercised since September, so nothing here is
speculative layout. Ownership is the argument inside the gear. A12's box shows
the remembered level, visible and erasable, because a stored preference the user
cannot read is not a preference they own. A06's gear is the whole learned map,
one removable row per kind. A02 spends an absorbed sibling as a single control
rather than reciting it. One layout rule binds the morph: its width math
hardcodes a single inner label, so an overflowing offer drops the second verb,
never truncates, and must read the same on a 2013 Air as on a desk monitor. The
signed-rule half of persistence lives here where the user can reach it: each
rule one readable line under the config rules directory, revocation the deleting
of that line rather than a rebuild, and evidence stays beside the launcher's own
stores.

**4.** Privacy is arithmetic because the stores are the only memory the register
permits, and each block states its at-rest shape and approximate bytes. The
shared base is twelve lifecycle rows near 32 bytes; A02 widens with a ring of
sixteen hashed kind-destination pairs near 0.3 kB; A08 keeps eight near 0.2 kB;
A10 holds a single 24-byte hour histogram; A14 stores nothing new, clearing a
store that already exists. A13 reads a header transiently for the presence of a
marker and never its contents, and its sentence is gated on that read so the
offer cannot lie. Nothing nameable rests: a site, command, file or title is read
live at the moment of speaking and dropped, per name-at-offer-time. One rule had
to be re-learned across the register: never learn from your own hand — a launch
Golem performed must not teach the launcher a ranking the user never made, the
lesson A17, A38 and A39 left this batch.

**5.** Admission is not a phase that ends when the blocks ship; it is governance
kept running against the finished product. The first hunt killed three of
fifteen on engine evidence and retired them without replacements, and the second
read the completed register field by field, repaired four, struck none, recording
each repair where the fault sat rather than in a preamble. The ladder is not
decoration. A08's only offer is its standing rule, because the user's own
repetitions were the tutorial; A09 has no automatic rung, because auto-opening
anything matching would run software nobody asked for; A12 never speaks to a user
who never accepted a level. Refusal is data that escalates toward silence, a
couple of them retiring an action, and an answered member of a cluster steps to
its back so the cluster drains and falls quiet. The notebook closes the ring
with every detector and its evidence, forgettable one line at a time.

**6.** Voice is a constraint the sentences are cut against, and it is why two
hunts never killed on it. Each register sentence passes the standing test — a
fact about a thing is an observation, a fact about a person is a verdict —
because the evidence is always a thing, never a guess about the user.
"That picture is about to leave and it still carries its metadata, do you want
it wiped?" is gated on the marker read, so it is only spoken when it is true.
"Your call just connected and your mic is still muted, do you want it opened?"
names a state the caller cannot feel, which is what makes it thankable rather
than a nag. Rarity is the feel: a dozen offers that mostly fall silent forever
once accepted, a download that moves once and rarely needs to speak again, a
level set once and remembered, "It's the hour you usually step away" where
"usually" is a histogram, not a habit the action invented. Under a budget of
three sentences a day, the register's voice speaks least exactly when the user
needs quiet most.
