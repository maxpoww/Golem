# implementation.md — batch 02

*The final. Two drafts got the batch's material onto the table and argued it; this
is the third independent pass, written from a blank page so the batch's own voice
survives whole. The register sentences and pill labels of `actions-40.md` are the
batch's named formulations and appear verbatim; every other line is re-thought.
Six numbered paragraphs, prose only, coverage fixed by conditions.md §2.*

---

**1.** Twelve actions are all that remain of the thousand habits this initiative
started with, and the reason is a rule rather than a mood: an offer deserves to
exist only where a sensed moment meets an able hand. The three kills of the first
hunt each broke one side of that pairing. A07's dock hides itself behind
fullscreen windows through the intellihide the engine already runs, so its
behaviour was owned before the sentence was written and there was no gap left for
it to fill. A11's parked machine had no host virtualization anywhere in the tree,
so the verb had no machinery to run even though the moment was reachable. A05's
caught corner had no global cursor stream, so the moment itself was unsensable.
Twelve survived because each keeps both halves: the stream that detects and the
mechanism that answers. Every one is deliberately slight — a condition, a single
sentence, one verb in the nested pill, a right-click that costs nothing, and a
gear box that grows from the sentence that just spoke.

**2.** Whether a block speaks on today's engine follows from one architectural
rule: nothing senses without already arriving. Detectors are pure functions over
streams the collectors carry — the audio watcher, the Hyprland event socket, the
zsh bridge's exit code, the downloads poll — and no detector owns a timer. The
batch therefore adds no new sensor; what the register tags [cheap] are rails and
reads, not sensing: a reachable-test subprocess on the git rail, one logind
listener shared by A10 and A14, an eval-rail write for the pointer. Persistence
is one layer with two homes — evidence (counters, hashes, medians, histograms)
under the launcher's stores, and a signed rule as one readable line in the
config rules directory; acceptance writes a rule, refusal only a counter. Two
ratified laws bind every Fires line: the day's budget is a priority queue ranked
by expiry rather than by kind, never two in an hour, no carryover; and one mouth
per cluster with back-of-the-queue on refusal. By that layer's own terms A09
and A12 speak today, their rails live; nine wait one read or counter deeper in a
collector that already runs; A13 waits on an actuator that is not ours to build
— two and nine and one, adding to twelve with no remainder.

**3.** The surface is carried over rather than designed, and ownership is its
argument. The pill, the nested verbs, the gear box and the grow morph come from
the sunset prototype that has been live since September, so the twelve blocks
speak through settled choreography instead of speculative layout. The gear is
where control is proven: A12's box shows the remembered mic level, visible and
erasable, because a stored preference the user cannot read is not a preference
they own; A06's gear is the whole learned map, one removable row per kind; A02
spends an absorbed sibling as one control instead of reciting it. One layout rule
binds the morph: its width math hardcodes a single inner label, so an offer that
would overflow drops the second verb rather than truncating, reading the same on
a 2013 Air and a desk monitor. The half of persistence the user can reach lives
here — each signed rule one readable line under the config rules directory, and
revocation is the deletion of that line, never a rebuild.

**4.** Privacy is stated in bytes because the stores are the only memory the
register permits, and the ledger adds to less than a kilobyte. Twelve lifecycle
rows sit near 32 bytes each as the shared base; A02 adds a ring of sixteen
hashed kind-destination pairs near 0.3 kB; A08 keeps eight near 0.2 kB; A10
holds a single 24-byte hour histogram; A14 stores nothing new, clearing a store
that already exists. A13 reads a header only to know a marker is present, never
what it contains, and its sentence is gated on that read so the offer cannot
lie. Nothing nameable rests anywhere: a site, command, file or title is read
live at the moment of speaking and dropped, per name-at-offer-time. The register
also obeys the law its earlier rows had to relearn — never learn from your own
hand — so a launch Golem performed must not teach the launcher a ranking the
user never made, the lesson A17, A38 and A39 left in place.

**5.** Admission is governance kept running after the blocks ship, and the two
day-shaping laws show their cost there rather than in a preamble. The first hunt
killed three of fifteen on engine evidence and retired them without
replacements; the second audited the finished register field by field, repaired
four and struck none, logging each repair where the fault sat. The ladder is
earned, never automatic: A08's only offer is its standing rule, because the
user's own repetitions were the tutorial; A09 has no automatic rung, because
auto-opening anything matching would run software nobody chose; A12 never speaks
to a user who never accepted a level. Refusal is data that escalates toward
silence — a couple of refusals retire an action, and an answered member of a
cluster steps to its back so the whole cluster drains and falls quiet. The
notebook closes the ring with every detector and its evidence, forgettable one
line at a time, which is what a budget of three sentences a day makes possible.

**6.** Voice is a constraint the sentences are cut against, and it is why two
hunts never killed on it. Each register sentence passes the standing test — a
fact about a thing is an observation, a fact about a person is a verdict —
because the evidence is always a thing, never a claim about the user. "That
picture is about to leave and it still carries its metadata, do you want it
wiped?" speaks only when the trigger has read the header and the marker is
really there. "Your call just connected and your mic is still muted, do you want
it opened?" reports a state the person in the call cannot perceive for themselves,
and precisely that makes the offer welcome rather than intrusive. Rarity is the
resulting feel: a dozen offers that
mostly fall silent forever once accepted — a download that moves once and rarely
needs to speak again, a level set once and remembered, "It's the hour you
usually step away" where "usually" is a histogram the action did not invent.
Under a budget of three sentences a day, the register speaks least exactly when
the user needs quiet most.
