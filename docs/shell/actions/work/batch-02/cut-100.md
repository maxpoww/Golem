# cut-100.md — batch 02, F4

*The privacy cut, per conditions.md §1 (F4) and Constitution VI (five laws, three
disciplines). Killed: anything needing content-reading, cloud, or
surveillance-feel that cannot be reformulated as gestures-not-content and
aggregates-not-diaries. The test applied to every line was Law VI.4, the
disclosure test: imagine Golem saying to the user's face what it tracked and
why — if the honest disclosure feels like being watched, or the only sentence
the detector can ever produce is an indictment, the candidate dies here.
Headline: this cut killed NOTHING — but not for lack of trying; the batch's
earlier cuts already removed F4's targets. The decision is argued in
`## Casualties worth noting`.*

**Result: 21 of 21 survive (0 killed).** The nominal "100" was never honestly
reachable, and no survivors were invented to approach it (Constitution VII —
padding a list to hit a number is the definition of slop). By primary
feasibility the tags are unchanged from F3: 11 ride [live] signals alone, 10
need at least one [cheap] addition, 0 depend on a [bridge] client or a [new]
collector. The structural reason for the zero: in THIS engine, the classic F4
condemners had no path to survive F3 at all — content-reading (writing/docs
spellcheck, table, citation), the browsing/media title diaries, the bank and
spend counters, the evening stopwatches and the aimlessness diagnoses were
already removed as unsensable (batch-02's F3 header and casualties), and the one
network actuator (room lights) died on VI.1. So F4's honest job became a focused
hearing, exactly as batch-01's F4 predicted for its own fraction: every survivor
below was put through the disclosure test and a reformulation pass, and where F4
imposes an at-rest shape or a verb rewrite it says so in `— P:`.

**The four F4 doctrines are binding on every line below (inherited verbatim):**

1. **Name-at-offer-time.** Detectors store hashes and counters at rest; every
   name a sentence needs (project, folder, app, level, file) is read LIVE from
   the world at the trigger moment. Nothing nameable sits on disk.
2. **No stopwatch over leisure.** Duration-of-pleasure detectors are surveillance
   regardless of aggregate shape, and every sentence they can utter is a guilt
   trip — double-death under VI (feel) and II (voice).
3. **Compulsion counters are indictments.** A counter whose only possible
   sentence is "you do this too much" (inbox re-checks, distraction loops) can
   never speak warmly.
4. **Transient classification is not content-reading.** Shape-checks read bytes
   to emit a CLASS and store only the class — the boundary between sensing and
   surveillance, already how the engine ships.

Survivor schema: `U0001 (T0001 S0039 H1328) [tag] (category) text — T: trigger
(signals [feasibility]) — P: note` — U-ids sequential, the H→S→T→U lineage
intact back through cut-250.md and cut-500.md to habits-1000.md. `— P:` notes
appear only where F4 imposes a reformulation or an at-rest constraint.

## Casualties worth noting

- **The cut killed nothing — decide whether that is a failure.** The disclosure test ran on every line, and the classes F4 exists to catch had no path TO this file: content-reading (writing/docs spellcheck/table/citation family) and the title diaries (browsing, media watch-lists) already died at F3 as unsensable; the bank/spend counters died with the finance category at F2/F3; the evening stopwatches (one-match-becomes-three, autoplay-past-stop, the evening "one thing") never survived F3's time-of-day extermination; aimlessness-inference died with the browsing category. Batch-01's F4 needed a knife because its 219 still carried those classes; batch-02's 21 simply do not. A focused hearing with zero kills, not a massacre with padding (Constitution VII).
- **T0007 format-before-commit — the closest call to content.** It is the only survivor whose detector touches the user's own file bytes (the formatter pass). It survives because the pass is transient and its only product is a dirty/clean class — but it is the one row F5 should re-hear hardest, because "you commit unformatted code" can tip from service into a quality nag the moment the user's frequency rises.
- **T0012 project→app pair — the most "knows my work" survivor.** It survives because the at-rest shape is (cwd-hash → app-class) × counter — a bounded pair histogram, never a per-session work log — and the offer quotes the live cwd, not a name pulled from disk (doctrine 1). Carries a deliberate F5 flag: would the user THANK "start the test runner, like you always do", or does it read as a schedule nudge?
- **T0017 "calibrate" — the hearable's verdict: an honest-verb rewrite, not a kill.** "Calibrate" promises a one-pass RTA the engine cannot perform without the user's voice; the reformulated verb [set the remembered level] is performable and honest. F4's gift to F5 is a verb that does what it says.
- **T0020 clear-agent-at-sleep — the hearable's verdict: keep, after naming the object.** The danger was the offer reading as "erase what I know about you" at bedtime. Naming the object kills the ambiguity — it clears Golem's OWN clipboard-history at $XDG_DATA_HOME, nothing else — and firing on any suspend (not the evening) removes the bedtime angle entirely. Privacy-POSITIVE: it deletes, it never observes.
- **T0014 brightness-between-calls — the one row that could have been a call AI.** The habit's phrasing implies knowing the gaps between calls; the reformulation rides the single live call-end event and stores nothing, so no call list and no durations exist to leak. The disclosure ("call's over — dim?") names the moment, not the user's schedule.
- **T0021 pointer-speed at fine task — "fine task" is a surface, not a mind.** The precision-class table derives from the focused window's class (image editor, CAD, pixel tool) the way meeting-class and game-class are derived elsewhere; it does not read the user's intent. Discloses cleanly: "you're in the pixel editor — want the mouse eased?"
- **T0003 download-destination — the hearable's verdict on "any names at rest?": none.** The download's kind (mime class) and the destination-dir identity are both hashed; the pair-counter is an aggregate; the destination is quoted live at the trigger and becomes a stored name only if the user accepts — at which point it is user-authored configuration, the same status batch-01 granted the accepted alias (U0015/U0093) and the cheat-sheet path (U0107).
- **T0009 corner-disarm — pointer discipline demo.** The pointer is sampled ONLY at a hot-corner activation event; at rest there is a per-corner counter. This is the same rule batch-01's U0154 (jiggle-the-mouse) earned and A26 then made compulsory: pointer state, never input capture, never a trajectory.
- **T0002 folder-empty and T0019 EXIF-strip — the two "touch my files" rituals** stay shape-only: file counts and ages (T0002), a transient header class (T0019); neither reads a filename's payload nor a pixel. T0019 is the stronger case because its verb REMOVES metadata, making it the batch's clearest privacy-positive action.
- **U0015/T0015 hibernate-at-lunch — the aggregate boundary held.** One median midday-idle hour is the exact shape batch-01's U0200 kept; it is a desk-away interval on the clock, and the sentence it can produce ("stepped away over lunch — hibernate?") is service, not an indictment. Doctrine 2 remains binding on the batch as a whole.
- **The honest number, restated.** 21 survived F3 and 21 survive F4 — there are no additional kills to mine, and manufacturing them would be slop (Constitution VII says so in so many words). The next instrument is the F5 usefulness bar, which several rows carry explicit flags for: T0012 (gift vs nudge), T0007 (service vs nag), T0021 (does anyone thank a slower mouse?), T0013 (is the command-not-found save worth a sentence?).
