# cut-50.md — batch 02, F5

*The usefulness cut, per conditions.md §1 (F5) and Constitution III + VII. One
question asked of all 21 survivors: **would a real user THANK Golem for this
offer?** Not "is the habit real" (F2), not "can we sense it" (F3), not "is it
clean" (F4) — would the sentence, arriving unbidden, land as a service? Killed:
nags, reminders-to-exist, anything the user's own reflex does faster than they
can read the sentence, and imagined helpfulness. Batch-02 runs a different shape
to batch-01: this tee had already been funnelled three times (250→500-survivors
was this batch's F2, then F3, then F4), so the cut is a sharp pass over a small,
already-lean field — not a massacre. The four deliberate F5 flags the F4 file
planted (U0012, U0007, U0021, U0013) are each ruled on IN WRITING in the
casualties.*

**Result: 15 of 21 survive (6 killed, 0 absorbed).** No padding toward 50 — the
razor stopped where the sentences stopped being thankable, and 15 is the honest
number (Constitution VII). The five F5 doctrines below are the instrument; the
six kills are argued one line each in the casualties. Survivors carry V-ids with
full lineage U→T→S→H intact (batch-01 shape V01–V40). Feasibility tags carried
forward unchanged from cut-100.md: 8 ride [live] signals, 7 stand on [cheap]
additions — the cut fell evenly across tags (3 [live], 3 [cheap]), see the

**The five F5 doctrines (binding, from batch-01/cut-50.md):**

1. **Already an OPTION is not an ACTION.** The shipped pill surfaces the verb
   whenever the context is live; a sentence that speaks first about the same
   verb adds noise, not initiative. Checked every survivor against
   options-catalog.md §4 + options-list.md (git.commit/push, media transport +
   volume, mic_mute, selection define/look-up/open-path, call_dnd, fullscreen_dnd,
   downloads.open/extract, shell.search_error, terminal_here, open_remote, high_cpu,
   files.open_here, find-in-page) and against batch-01's 34 shipped blocks.
2. **The one-keystroke test, and its exception.** If the user's own reflex is
   faster than reading the sentence, a per-instance offer is a toll, not a
   service; a ONE-TIME offer (or one standing-rule offer) that deletes the
   reflex forever is a gift.
3. **No verb, no action.** An insight with no hand to offer is a notification.
4. **The hand-back rule.** Golem owes a summary only of what Golem silenced.
5. **Sense the state, never impute the motive; never teach the user their own tool.**

- **U0018 boost-the-speaker-over-the-fan — doctrine 1, the verb is shipped.** The sink-volume verb IS `media volume` (a live OPTION, catalog §4.4, one of the seven proven slices). The fan event justifies noticing the volume knob is low; the sentence still only asks to press a knob already on the bar — "a sentence that speaks first about the same verb adds noise, not initiative."
- **U0014 brightness-between-calls — the toll twin of A38.** Batch-01's shipped A38 (the second knob) owns the dim-the-display verb in the evening; U0014's per-instance call-end dim is the user's own demonstrated reflex (they did it ≥3×), so an offer races their own hand; and its standing form is A38 wearing a suit.
