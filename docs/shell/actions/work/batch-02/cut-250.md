batch-01 precedent: zero bridge survives F3.*

batch 01 already mined the same sixteen categories to their floors and nearly
every survivor here is a re-offer of an already-owned moment. No padding down to
a number and none up (Constitution VII): the nominal 250 was never reachable and
no kills were manufactured to approach it.
