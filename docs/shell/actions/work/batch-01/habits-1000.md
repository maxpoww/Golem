# habits-1000.md — batch 01, F1

*1000 habits of computer users, one line each, schema per conditions.md §2.
Legend: **[observed]** = found in a named, checkable source (inline in parens) ·
**[reasoned]** = enumerated from first principles. Honesty rule: no fabricated
statistics; an honest [reasoned] beats a fake [observed].*

**Chunk plan (categories per chunk, no cross-chunk repeats):**
- Chunk 1 (H0001–H0250): browsing, communication, media (incl. gaming), files
- Chunk 2 (H0251–H0500): coding/work tools, writing/docs, system/settings, search/launch
- Chunk 3 (H0501–H0750): power/battery, audio/devices, window/workspace management, security/privacy rituals
- Chunk 4 (H0751–H1000): health/ergonomics, time-of-day rituals, finance/shopping, learning/reading

Observed anchors used in chunk 1 (from 4 web searches, 2026-09-08): Chang et
al. "When the Tab Comes Due" (CHI 2021) on tab hoarding; Gloria Mark (UC
Irvine) on email/attention interruptions; CloudCover Music workplace survey on

daily+; 51% of professional devs use AI tools daily); Meyer, Barton, Murphy,
Zimmermann & Fritz, "The Work Life of Developers" (CHI 2017 — ~47 activity
switches/hour, highly fragmented workdays). Everything else is [reasoned].

Observed anchors used in chunk 3 (4 web searches, 2026-09-08): GoDaddy
Consumer Pulse 2025 (61% of US consumers reuse passwords across accounts); HP

Robertson, "Display space usage and window management operation comparisons"
(AVI 2004 — single-monitor users switch via taskbar more; multi-monitor users

of power/battery is honestly [reasoned].

Observed anchors used in chunk 4 (5 web searches, 2026-09-08): "Prevalence of
