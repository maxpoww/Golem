# LIST 2 — OPTIONS

*The curated list. Max's file: cut, rename, reword, kill whole groups.
Proposed 2026-09-12; nothing is built from it until he has been through
it. Contexts come from [contexts.md](contexts.md).*

**Format — two lines per OPTION:**

```
Name — the effect
Shows in: context · the moment
```

Line 1 is what it is called and what it does. Line 2 is the context that
surfaces it, and where a bare context would be a *trait* rather than a
*moment*, the moment is named after the `·`.

---

## The razor used to curate this

**The shell only offers what the app cannot.** Undo is Ctrl+Z and belongs
to the drawing program; offering it is a toll on someone who already has
the reflex. What the shell is uniquely positioned for is **windows,
devices, interruption, capture, the clipboard, files that just appeared,
and system state** — the seams *between* programs, which is precisely
where a user has no muscle memory and every app disagrees.

Applied honestly, this killed most of what was in the tree before: an
offer keyed to "a browser is focused" is a **trait**, not a moment, and a
bar built from traits is a toolbar that changes shape.

Second razor, from the constitution: **astuto, no dirigido.** Put the
means in reach; let the user perform the act. Nothing on this list
explains anything.

## Universal — the moment, not the app

```

Shows in: gaming, watching, presenting, on a call · you go fullscreen, or a call starts

Keep this on top — pins the window above the others
Shows in: drawing, video editing, coding, 3D · a second window is being used as reference

Bring the noise here — focuses whatever window is making sound
Shows in: any · audio is playing from a window you cannot see

Pick a colour — eyedrops any pixel on screen to the clipboard

Grab this window — puts a shot of it on the clipboard
```

**35 OPTIONS across 17 contexts.** Contexts with nothing yet: messaging,
music production beyond the export, gaming beyond DND, files beyond the

would be the thing this list exists to stop.

## What is NOT here, and why

- **Find in page, undo, save, next slide, next track.** One keystroke the
  user already owns. Offering them is a toll, not a service.
- **Anything keyed to "app X is focused".** A trait, not a moment.
- **Anything that explains.** *Dirigido*, by construction.
- **Anything needing a browser extension or a store upload.** Documented
  as blocked in catalog.md §8 and still blocked.
- **An "empty space" OPTION.** Asked for, built and cut on **2026-09-13**:
  a pill on any workspace with no windows, in the sunset module's shape —
  first a plain sentence, then with a gear and a settings box, then
  briefly reporting system facts (tasks elsewhere, battery, disk, network,
  update, CPU) with a readout panel. Max on seeing it: *"it sucks, get rid
  of it… i meant the whole pill.. all, get rid of it. we are gonna use
  another aproach."* The moment is real and unclaimed — an empty room is
  still the one place where nothing competes for attention — but this was
  not the shape for it. Do not rebuild it from this description.
