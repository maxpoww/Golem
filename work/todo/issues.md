Priority 1 — the daily loop (this is 80% of what an ISO user touches):
- Dock: edge reveal, auto-hide, intellihide dodge/park, magnification feel, launch bounce, window thumbnails. Does it ever get stuck hidden, stuck visible, flicker, or reveal when it shouldn't?
- Openbox: scroll-expand, type-to-search (speed, ranking feel, does the best match feel right?), Escape behavior, section paging, group open/close motion, drag-to-pin, drag-to-reorder glide. Any jank, any icon that's wrong/tofu/letter-tile that shouldn't be.
- Install section: search a few packages, look at icons, drag one to install, watch the "Installing…" state, drag one out to uninstall. Does failure ever leave a cell stuck?

Priority 2 — the OPTIONS surfaces (newest code, least eyes so far):
- Clipboard box: copy various things (text, images, URLs from browser, URLs from terminal), check every row renders right, open the detail view, scroll long entries, link share-cards (hero image vs glyph), the copy-link pill — this one is days old and has had the least testing of anything: try it on Chrome, a webapp window, Firefox if you use it.
- Dictionary: real usage — accents, words in both languages, missing words, scrolling long entries, Back button, does the box ever get stuck grabbed/open?
- Notifications box: DND toggle, card actions, long notification content, many notifications at once.
- Topbar pills: window controls on different apps, clock, hover behaviors.

Priority 3 — the feel pass (only you can judge this):
Motion quality everywhere — anything that stutters, overshoots, feels slow, feels abrupt, or breaks the "Shinings" language. Colors/contrast that read wrong. Anything that makes you hesitate — a stranger will hesitate ten times harder.
